# GROUP YELLOW — Waste Management on Campus

Complete 20-question survey + Supabase database + private admin dashboard.

1. Create/open your NEW Waste Management Supabase project.
2. SQL Editor → New query → paste `supabase.sql` → Run.
3. Authentication → Users → Add user and create the admin account.
4. Open `config.js` and replace the two placeholders with the NEW project's Project URL and Publishable/anon key.
5. Upload all files to GitHub Pages.
6. Public survey: `index.html`
7. Private dashboard: `admin.html`

Q5, Q12 and Q16 allow multiple selections. Q5, Q6, Q12 and Q16 have optional Other fields where the survey specifies them.

Never place a Supabase service_role/secret key in the website.
